01 /

Overview

The Bel-is Tourism Management System was developed to provide a digital platform for promoting Barangay Bel-is and making its tourism information more accessible to visitors.

The project combines a tourism website, management system, and virtual tour. My contribution focused on the user interface design and front-end development of the website.

02 /

Problem

Information about local tourism destinations can be difficult to discover when it is scattered across different sources and lacks a centralized digital presence.

The project aimed to create a more accessible and engaging way for visitors to discover Bel-is and learn about its tourism destinations.

03 /

Approach

I focused on creating a clear and engaging interface that would make tourism information easy to explore and navigate.

I designed the website interface in Figma before translating the designs into a functional frontend using Vue.js. I also developed the frontend of the virtual tour, creating the interface and interactions needed for visitors to explore the destinations digitally.

04 /

Solution

The project provides a tourism website where visitors can explore destinations and access information about Barangay Bel-is through a centralized digital experience.

I contributed to the project by designing the user interface in Figma and implementing the frontend using Vue.js, translating the designs into a functional and responsive website.
